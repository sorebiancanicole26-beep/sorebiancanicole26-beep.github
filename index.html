5. Problem-Solving & Analytical Case Studies

Real-world technical troubleshooting and empirical data analysis.

Case Study 1: Resolving Windows Setup Loop via Registry

Issue: Encountered a persistent system configuration error loop during an operating system reinstallation on an MSI laptop.
Resolution: Utilized Command Prompt at setup to launch the Windows Registry Editor (`regedit`), navigated to `ChildCompletion`, modified the setup execution status value, and cleared the boot cycle error to complete setup successfully.

Case Study 2: IT Service Center Performance & Correlation Analysis

Issue: Analyzing 50 school IT tickets to identify bottlenecks in response times and customer satisfaction.
Findings & Resolution: Identified Software and Network issues as 60% of all requests. Calculated a moderate-to-strong negative correlation (r = -0.59) between resolution time and satisfaction rating, proving faster resolution directly drives higher user rating. Recommended automated password reset systems and dedicated network toolkits.
