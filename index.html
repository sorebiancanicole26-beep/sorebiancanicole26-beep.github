Problem-Solving Portfolio

Real-world IT troubleshooting cases, system diagnostics, and root-cause analytics.

Case 1: Windows Setup Error Loop Resolution via Registry Editor

Problem: Encountered a persistent setup error loop ("Windows could not complete the installation") during a clean Windows 11 OS reinstallation on an MSI laptop.
Possible Causes: Interrupted setup execution flags or corrupted configuration keys within the Windows Registry.
Diagnostic Procedure: Accessed Command Prompt at the error screen using Shift + F10 and launched the Windows Registry Editor by executing regedit.
Solution: Navigated to HKLM\SYSTEM\Setup\Status\ChildCompletion, modified the execution status value from 1 to 3, restarted the setup sequence, and successfully completed OS bootup.
Lesson Learned: Advanced knowledge of the Windows Registry and CLI utilities is essential for emergency OS recovery without requiring full drive re-formatting.

Case 2: Local DNS Cache Corruption & Web Connectivity Failure

Problem: Web browser failing to load live GitHub Pages deployments despite an active Wi-Fi connection.
Possible Causes: Stale or outdated local DNS resolver cache entries following domain updates.
Diagnostic Procedure: Executed network CLI commands (ping google.com and ipconfig /all) to verify IP gateway routing and packet transmission.
Solution: Executed ipconfig /flushdns in Command Prompt to clear the DNS resolver cache, instantly restoring domain name resolution and website access.
Lesson Learned: Standard CLI diagnostic utilities provide fast, effective resolution for network-layer cache inconsistencies.

Case 3: Mitigating High Network Downtime Bottlenecks in Campus Wi-Fi

Problem: Low user satisfaction ratings and frequent connection drops reported at the Campus Student Center.
Possible Causes: Localized network infrastructure bottlenecks resulting in excessive downtime based on empirical data.
Diagnostic Procedure: Constructed an Excel PivotTable to analyze average downtime across campus locations (Student Center recorded the highest at 28.20 mins avg).
Solution: Recommended targeted access point hardware upgrades and scheduling maintenance during off-peak hours to mitigate correlation impact (r = -0.748).
Lesson Learned: Data analytics provides verifiable evidence to isolate root causes in network infrastructure rather than relying on guesswork.

Case 4: Optimizing Resolution Delays in IT Service Center Tickets

Cybersecurity Case Study

Defensive security analysis and SQL Injection prevention in web applications.

🛡️ SQL Injection (SQLi) Vulnerability Case

1. What is the vulnerability?
SQL Injection (SQLi) is a security flaw where attackers inject malicious SQL commands into web input forms to manipulate backend database queries.

2. How can it happen?
It happens when application input fields (like student login or search forms) merge user text directly into raw SQL statements without sanitization.

3. What are the risks?
Bypassing authentication, unauthorized access to sensitive student records, data leakage, and destructive operations like table deletion.

4. How can developers prevent it?
Use Prepared Statements / Parameterized Queries to separate logic from input, enforce strict input validation, and apply the principle of least privilege.

5. What security practices should be implemented?
Enforce HTTPS SSL encryption on live GitHub Pages deployments, hash stored credentials, and avoid exposing API keys or secrets in public code repositories.

Troubleshooting Case & AI Usage Log

🛠️ Troubleshooting Case #01: Windows 11 Installation Loop

Problem: Persistent setup error loop during clean Windows 11 OS reinstallation on an MSI laptop.

Possible Causes: Corrupted execution state flags under the Windows Registry configuration during setup.

Diagnostic Procedure:

  1. Opened Command Prompt during setup using Shift + F10.
  2. Launched Registry Editor by typing regedit.
  3. Navigated to HKLM\SYSTEM\Setup\Status\ChildCompletion.
  4. Identified setup.exe DWORD value improperly set to 1.

Solution: Modified setup.exe DWORD value to 3 and restarted via CLI using shutdown /r /t 0.

Lesson Learned: Understanding low-level registry keys and CLI tools is essential for resolving system boot errors independently.
